# Clean public release

This repository starts with fresh public history and contains allowlisted reusable source, tests and a minimal intentionally public demo. It is not a history rewrite of an earlier private application.

Excluded: real environment files, deployment linkage, personal datasets and editorial builders, research candidates, copied creator descriptions, bulk HN comments, platform enrichment dumps, feedback exports, screenshots and private deployment addresses.

A public release does not publish the hosted private edition or browser-local profiles. Any future dataset addition needs its own privacy and redistribution review. Do not infer that a secret scanner establishes content rights.
