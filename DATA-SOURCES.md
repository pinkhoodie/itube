# Public demo and data boundaries

This repository includes a minimal editorial demonstration of mixed-source playback. Display labels, summaries and example reasons are original explanatory text written for this generic release, not a person's inferred tastes or feedback. Source identifiers, creator attribution and original publication dates identify the public works; they are not account credentials.

- YouTube example: Sagar Batchu's agent-permissions talk, published by AI Engineer: https://www.youtube.com/watch?v=JxNCuXkSWyQ. Original publication: 2026-11-02. The demo does not reproduce its full description, tags, view/like counts, transcript or video file.
- X example: Pratik Gandhi's public computer-use demonstration: https://x.com/pratikg/status/2116383901115711897. Original publication: 2026-10-31. The demo does not reproduce the full post text, fetched media cache or video file.

Media loads through official third-party embeds, with original-source fallbacks. The small demo is intentionally public and not evidence of anyone's private viewing behavior. It is not continuously refreshed.

## Optional upstream collection

HackerTube: https://hackertube.org/data, derived from https://huggingface.co/datasets/open-index/hacker-news. The upstream database states ODC-By 1.0 (https://opendatacommons.org/licenses/by/1-0/). Preserve its attribution and examine its own documentation before separately using it. Individual comments remain authors' work; platform-derived metadata and copied descriptions require separate consideration. No claim is made that all such content inherits the application's license or database license.

Private editions and caches belong outside this repository, such as the ignored `private-data/`, `research/` and `data-cache/` directories. `.vercelignore` controls deployment upload, not GitHub publication. Never commit local feedback exports or secrets.
